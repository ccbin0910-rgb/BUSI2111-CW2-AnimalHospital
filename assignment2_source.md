Purpose
The second computer lab session demonstrates the procedures used to create a relational
database from an entity-relationship (ER) diagram and a data dictionary. You will
practice the skills you need to complete the second group assignment in the lab. The lab
uses REA (Resources, Events, Agents) diagrams and references to create tables. Please
read the relevant chapters and review your lecture notes and the in-class activities to
obtain an overview of REA modeling and implementation in a relational database.

Knowledge Objectives
      The lab provides an exposure to the following areas:

      Create Relational Database and Database Tables
       Create a new relational database.
       Create new database tables.
      Format database table fields.
       Provide data input controls by including data input restrictions.

      Establish Relationships
        Establish relationships between tables.
       Enforce referential integrity.

     Document Database Information
      Document table definitions and the relationship window

Vocabulary

       Table         A table is a collection of data about a specific topic, such
                             as inventory or sales.
        Field         A column entry in a table of data. Each piece of
                            information in a table is stored in a predefined area called
                           a field. For example, an inventory table contains fields
                                that describe the product and list the price of the product.
      Record         A row entry in a table of data. Each record is identified
                           with a unique identifier or number.

Assignment Description

You have been hired to develop an information system for the
UNNC Animal Hospital, which is owned by Dr. Nottingham and
three other veterinarians. Dr. Nottingham currently owns a personal
computer but uses the computer only for word processing. Dr.
Nottingham wants to use the system you have been hired to develop
to maintain pet histories and accounting information. He has
high hopes and is counting on you to help him through this change.

After the owners agreed to your development plan, they provided the following overview of the
operation.

When a new customer comes to the Animal Hospital, the “parents” of the pets are required to
complete an introductory form that includes the following:
         •   Parent name
         •  Address
         •  Day phone
         •  Evening phone

The parents are also required to provide the following information about each pet (Note:
some people own many pets!):
         •   Pet name
         •  Breed
         •   Color
         •   Birth date

The introductory information is to be stored so parents do not have to provide the same
information each time a pet has an appointment.

The doctors see only one pet during each appointment. For example, if Dr. Nottingham is
going to see Emily’s two cats, then two appointments are established. For each appointment,
the pet’s weight, the reason for the appointment, and the doctor’s diagnosis is recorded.
Depending on the diagnosis, the doctor may prescribe any number of medicines to cure the pet.
